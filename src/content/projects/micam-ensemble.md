## Overview

This project extends MiCaM to explore how different motif-mining and ensemble choices affect molecular graph generation. It connects an interest in structured representations with the construction of molecular structures.

The repository contains alternative vocabulary-construction strategies, changes to preprocessing and model components, and experiment logs for comparing these variants.
